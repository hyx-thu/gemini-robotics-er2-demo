# Spot Fiducial Tag Sheets

These sheets use AprilRobotics `tag36h11` AprilTag images.

Print guidance:

- Print at 100% scale / actual size.
- Do not use fit-to-page scaling.
- Use matte paper or card stock.
- Keep tags flat, clean, and well lit.
- Mount each tag rigidly on a wall or post.
- Do not reuse the same tag ID in the same mapped area.
- Start with large tags for hallways or longer viewing distances.

Generated sheets:

- `tag36h11-large-letter.html`: one 120 mm tag per page.
- `tag36h11-compact-letter.html`: four 82 mm tags per page.

Open either HTML file in a browser and print it.
